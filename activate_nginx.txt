# NGINX HTTPS local

Terminal 1 — app:

```bash
cd /Users/franciscomedeiros/fastapi_training
export FRONTEND_PORT=3000
./run.sh
```

Terminal 2 — proxy:

```bash
cd /Users/franciscomedeiros/fastapi_training
npm run nginx:cert
npm run nginx:render
nginx -t -c "$PWD/deploy/runtime/nginx-https.conf"
nginx -c "$PWD/deploy/runtime/nginx-https.conf"
```

PowerShell (terminal 1):

```powershell
cd /Users/franciscomedeiros/fastapi_training
$env:FRONTEND_PORT = "3000"
./run.sh
```

PowerShell (terminal 2): troque `$PWD` por `$($PWD.Path)` nos caminhos do nginx.

Abrir:

```text
https://localhost:8443
http://localhost:8080   # redireciona pro HTTPS
```

Reload: `nginx -s reload -c "$PWD/deploy/runtime/nginx-https.conf"`

Stop: `nginx -s stop -c "$PWD/deploy/runtime/nginx-https.conf"`
