# Activate local NGINX HTTPS proxy
# Ativar o NGINX proxy localmente

## Bash

```bash
cd /Users/franciscomedeiros/fastapi_training

export FRONTEND_PORT=3000
./run.sh
```

Second terminal:

```bash
cd /Users/franciscomedeiros/fastapi_training
npm run nginx:cert
npm run nginx:render

nginx -t -c "$PWD/deploy/runtime/nginx-https.conf"
nginx -c "$PWD/deploy/runtime/nginx-https.conf"
```

## Open

```text
https://localhost:8443
http://localhost:8080
```

## Reload

```bash
nginx -s reload -c "$PWD/deploy/runtime/nginx-https.conf"
```

## Stop

```bash
nginx -s stop -c "$PWD/deploy/runtime/nginx-https.conf"
```
